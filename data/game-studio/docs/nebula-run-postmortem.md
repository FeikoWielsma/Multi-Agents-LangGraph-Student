## What happened

Nebula Run shipped two weeks late. The Coder and the Artist worked from different copies of the brief, and the sprites
did not fit the grid.

## What changed

One project board holds the brief, the rules, the code and the bugs. Every crew member reads the board and writes to it.
Long briefs go to a crew member with a clean context, so nobody reads what they do not need.
